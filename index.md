# 📘 Git & GitHub Essentials Wiki

Welcome! This is a beginner-friendly guide to Git and GitHub, written for people with no coding background.

Whether you've never opened a terminal before or you've heard terms like "commit" and "pull request" and felt lost — this wiki is for you.

## 💡 Why This Wiki Exists

Most Git tutorials assume you already think like a programmer. This one doesn't. Every page uses everyday analogies (folders, snapshots, save points) instead of jargon, so you can build real confidence using GitHub — even if you've never written a line of code.
