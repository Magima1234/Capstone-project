# 📘 Git & GitHub Essentials Wiki

A beginner-friendly documentation project that explains Git and GitHub concepts in plain language for non-programmers. This wiki was built as a course project for "GitHub Essentials for Non-Programmers."

## 📖 Project Description

Many people who are new to tech find Git and GitHub confusing — full of unfamiliar terms like "commit," "branch," "push," and "pull request." This wiki breaks those concepts down into short, clear, jargon-free pages that anyone can follow, regardless of coding background.

The goal is simple: help a complete beginner go from "What is Git?" to "I can confidently manage my own repository" in under an hour of reading.

## 🎯 Purpose

- Provide an easy reference for absolute beginners learning Git/GitHub
- Practice proper GitHub workflow: repository structure, README writing, meaningful commits, and Markdown documentation
- Demonstrate the ability to publish a documentation site using GitHub Pages

## 🛠️ How GitHub Was Used

- Repository created to host all project files with a clear, descriptive name
- Folder structure organized to separate documentation (docs/) from project metadata
- Markdown used throughout for all documentation pages
- Commits made incrementally with meaningful messages as each page was added
- GitHub Pages enabled on the main branch, /docs folder, to publish the wiki as a live website
- Issues tab (optional) used to track future improvements/content ideas

## 🚀 How to Use This Wiki

1. Visit the live site or browse the docs/pages/ folder directly on GitHub
2. Start with Introduction, then work through the pages in order
3. Use the Glossary any time you hit an unfamiliar term
